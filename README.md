# OM2Server
This is a basic python script for batched downloads of files from my Olympus EMD5 mkIII, with subsequent rsync backup to home server. 

Set your camera's SSID, your home network's SSID, remote server's username, password, and remote path. The script will handle connecting to the camera, and your home network, back and forth as needed, to download files off the camera and upload them to the server.
